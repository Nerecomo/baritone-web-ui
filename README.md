# Baritone Web UI + Forge Bridge

Универсальный локальный веб-интерфейс для управления Baritone и просмотра инвентаря Minecraft через Forge Bridge.

## Состав

- `site/` — автономный сайт без каталогов и иконок конкретной версии Minecraft.
- `bridge-source/` — исходный проект Forge Bridge.
- `BaritoneWebBridge-Forge-1.19.2-2.5.2.jar` — готовый мод для Forge 1.19.2.
- `BaritoneWebBridge-Forge-1.19.2-2.5.2-sources.zip` — архив исходников релиза.

Иконки предметов и блоков рендерятся самим Minecraft, поэтому поддерживаются предметы из установленной модовой сборки. Bridge кеширует PNG на диске; размер кеша и кнопка открытия его папки отображаются на сайте.

Логи Bridge ротируются примерно на 8 МБ, чтобы не расти бесконечно.

Подробности запуска находятся в [RELEASE-README.txt](RELEASE-README.txt).
