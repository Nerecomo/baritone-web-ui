site\                  Чистый сайт с рендерингом иконок через Bridge.
BaritoneWebBridge-Forge-1.19.2-2.5.2.jar
BaritoneWebBridge-Forge-1.19.2-2.5.2-sources.zip
bridge-source\         Синхронизированный исходный проект Bridge 2.5.1.

Иконки предметов и блоков запрашиваются у Bridge и рендерятся Minecraft.
Сайт не содержит каталогов, текстур или иконок конкретной версии Minecraft.
Блоки указываются универсальными ID: minecraft:block или modid:block_name.
Кнопка кеша рядом с настройками показывает его размер и открывает папку.
Bridge ограничивает основной и предыдущий лог файлами примерно по 8 МБ.
Крафтинговые ячейки инвентаря по умолчанию скрыты; их можно включить в
настройках сайта после открытия окна настроек.
