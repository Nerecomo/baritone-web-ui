Global release 2.5.6

О проекте
Это локальная веб-панель для управления Baritone в Minecraft. Сайт отвечает
за интерфейс, а Forge Bridge передаёт команды в запущенную игру и возвращает
результат.

Быстрый запуск
1. Поместите JAR Bridge в папку mods.
2. Запустите Minecraft.
3. Откройте site\site.html.
4. Выберите нужную функцию и отправьте команду.

Основные возможности
- команды перемещения, поиска, добычи и строительства;
- выбор блоков текущей модовой сборки;
- просмотр инвентаря и состояния Bridge;
- иконки, отрендеренные самим Minecraft;
- автоматический каталог и кеш иконок;
- кнопка открытия и очистки кеша;
- скрытие крафтинговых ячеек в настройках;
- ротация логов для ограничения занимаемого места.

site\
  Универсальный статический сайт без каталогов и текстур конкретной версии Minecraft.

BaritoneWebBridge-Forge-1.19.2-2.5.6.jar
  Готовый Forge-мод для Minecraft 1.19.2.

BaritoneWebBridge-Forge-1.19.2-2.5.6-sources.zip
bridge-source\
  Синхронизированные исходники Bridge 2.5.6.

При первом подключении Bridge сканирует Forge-реестры текущей модовой сборки,
сохраняет catalog JSON в кеш и передаёт сайту список доступных блоков.
После этого Bridge в фоне последовательно создаёт дисковый кеш иконок всех
зарегистрированных предметов, не блокируя запуск сайта и Minecraft.

Сетевое поведение:
- Bridge слушает только 127.0.0.1.
- Используется первый свободный порт из диапазона 8765–8795.
- Каждый отдельный Minecraft-клиент получает собственный порт.
- Сайт автоматически опрашивает этот диапазон раз в 10 секунд.

Иконки рендерятся самим Minecraft и кешируются в директории игры.
Кнопка кеша рядом с настройками показывает его размер и открывает папку.
Кеш можно очистить после закрытия Minecraft — он восстановится автоматически.

Логи Bridge ротируются примерно на 8 МБ: основной и предыдущий лог вместе
не должны занимать больше примерно 16–17 МБ.

Крафтинговые ячейки инвентаря по умолчанию скрыты и включаются в настройках сайта.
